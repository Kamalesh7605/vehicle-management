# Database

FleetMate uses MySQL 8. There is no hand-written `init.sql`: the schema is generated by Hibernate
(`quarkus.hibernate-orm.schema-management.strategy=update`) on backend start, and demo data is loaded by
`DemoDataSeeder` when the `vehicles` table is empty (disable with `SEED_DEMO_DATA=false`).

Tables: `users`, `vehicles`, `drivers`, `vehicle_driver_assignments`, `fuel_records`, `maintenance_records`,
`expenses`, `documents` - all with numeric primary keys, foreign keys, and `created_at` / `updated_at`.
Unique constraints: `vehicles.vehicle_number`, `drivers.licence_number`, `users.email`.

For production, switch the strategy to `validate` and manage migrations with Flyway or Liquibase.
